## CRT 效果性能优化（第二轮，不改变画面表现）

### 优化内容
1. **扫描线路径合并**：同色扫描线合并到单个 Path，`stroke()` 调用从 ~1350 次/帧降至 3 次/帧
2. **OffscreenCanvas 缓存暗角/四角效果**：gradient 不再每帧重建（原先每帧 10 个），仅当 `distortionPhase` 变化超过 0.08 阈值或尺寸变化时才重绘离屏 canvas，其余帧直接 `drawImage` 拷贝
3. **CSS 合成层优化**：`.crt-effect` 添加 `will-change: contents` + `contain: strict`，使用 `100vw/100vh` 替代 `100%`

### 保持不变
- 所有 CONFIG 参数（VISUAL 下全部数值）完全未修改
- 绘制逻辑（扫描线弯曲、暗角渐变、四角阴影/色差）参数和算法不变
- 画面表现与优化前完全一致

## ASCII Logo 优化（logoRandomizer.js + logo.css）

### 修复的问题
1. **hover 缩放覆盖 JS 缩放**：CSS hover 写死 `scale(1.08)` 会覆盖 JS 计算的适配比例 → 改用 CSS 变量 `--logo-scale`，hover 时 `scale(calc(var(--logo-scale) * 1.08))`
2. **DOM 测量优化**：整段文本插入 DOM 测量 → 只测一个字符宽度并缓存，用 `maxChars × charWidth` 计算
3. **fetch 无容错**：加载失败时 logo 空白 → 加 try/catch，失败时静默保持空白不破坏布局
4. **缩放策略**：保持原始纯宽度缩放（高度溢出靠 overflow:hidden 裁剪），不加高度约束
