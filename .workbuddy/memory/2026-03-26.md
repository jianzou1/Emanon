3. P1: Netlify `_headers` 缓存策略
4. P2: Tab prefetch 升级 / favicon 优化
5. P3: Service Worker (长期)

### 方案 1：preload/preconnect（header.ejs）
- `ejs/templates/header.ejs` 新增 7 个 `<link>` 标签：

  - 2 个 `<link rel="preconnect">` — cdn.jsdelivr.net + unpkg.com（高频 CDN，提前完成完整握手）

### 方案 2：JSON 数据共享缓存层
- 新建 `js/dataCache.js`：缓存 Promise 本身（非结果），同一 URL 多个调用者共享同一 Promise
- 改造 3 个消费模块：

  - `gallery.js` — 移除 `fetchGalleryConfig()` 和 `fetchSystemConfig()`，改用 `fetchJSON()`
- 效果：`game_time_cfg.json`(27KB) 从 2 次请求降为 1 次，`system_cfg.json` 从 3 次降为 1 次

## CDN 配置统一化
- **问题**：header.ejs 硬编码 preconnect/dns-prefetch 域名，cdnLoader.js 也硬编码 CDN URL，两处维护易遗漏
- **方案**：新建 `cfg/cdn.json` 作为唯一 CDN 配置源
  - 包含 `pjax`/`css98`（运行时 URL）+ `preload`/`preconnect`/`dnsPrefetch`（构建时标签）
  - `cdnLoader.js`：`import CDN_CONFIG from '../cfg/cdn.json'` 替代硬编码的 `CDN_CONFIG` 对象
  - `webpack.config.js`：`require('cfg/cdn.json')` 注入到 EJS 模板参数 `cdn`，同时更新 ejs.render preprocessor 参数
  - `header.ejs`：`<% cdn.preload/preconnect/dnsPrefetch.forEach(...) %>` 动态生成标签
- 构建验证：7 个 HTML 页面均正确生成 1 preload + 2 preconnect + 4 dns-prefetch 标签，main.js 包含全部 5 个 pjax CDN URL

## 自动构建时间戳替代手动版本号
- **问题**：langManager 中的 `version: '3.1'` 需手动维护，header.ejs preload 也硬编码 `?v=3.1`
- **方案**：webpack 构建时 `Date.now().toString(36)` 生成 `buildHash`
  - `webpack.DefinePlugin` 注入 `__BUILD_HASH__` 到 JS 运行时
  - `langManager.js`：删掉 `version` 配置，fetch URL 改用 `__BUILD_HASH__`
  - `cdn.json`：preload href 去掉版本号，新增 `cacheBust: true` 标记
  - `header.ejs`：`cacheBust` 为 true 时自动拼接 `?v=<%= buildHash %>`
  - `webpack.config.js`：templateParameters 和 ejs.render preprocessor 都传入 `buildHash`
- 效果：每次 `npm run pack` 自动生成新的缓存破坏参数（如 `?v=mn7g5a63`），HTML preload 和 JS fetch 保持一致
