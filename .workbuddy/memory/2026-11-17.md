## 预加载优化（已实施）

用户批准了编号 1-4 四项，P2 三项（ASCII 延迟、cfg JSON 版本号、lang 内联）暂不做。

### 改动
1. **98.css 移入 head**：`ejs/templates/header.ejs` 新增 `<link rel="preload" as="style">` + `onload` 转 stylesheet + `__load98Css` 内联降级 + `noscript`。`js/cdnLoader.js` 删掉 `loadStylesheet`/`loadExternal98Css`/`loadResources`，只保留 `loadPjax`。
2. **pjax 惰性化**：`js/main.js` 新增 `getPjax()` 单例；`handlePageLoad` 不再 await 它；popstate 在 pjax 未加载时接管后退。
3. **页脚去 GitHub API**：`webpack.config.js` 注入 `__BUILD_TIME__`；`js/footerLoader.js` 用 `getBuildTime()` 取代整段 fetch + AbortController + localStorage 缓存。
4. **预取调度**：新增 `js/prefetch.js`（`shouldSkipPrefetch` + `onIdle`）；`warmUpCache` 与 `preloadTabs` 改为空闲执行并跳过省流/2G；Safari 兜底从 `setTimeout(200)` 改为 load 后 1200ms。`cfg/cdn.json` 移除死掉的 `api.github.com` 预取。

**额外收益**：`TabHandler` 新增 `fetchTabContent()`，缓存未命中时只补取单个页签，页签切换彻底不依赖 pjax。构造签名去掉 pjax 参数。

### 实测（Fast 3G / 150ms RTT / 本地静态服务）

|---|---|---|
| 98.css 开始下载 | 826ms | 176ms |
| 98.css 生效 | 1174ms | 633ms |
| FCP | 604ms（无 98.css） | 656ms（98.css 已生效） |
| 页签可点击 | ~1407ms | 910ms（-35%） |

FCP 绝对值晚了 52ms，因为 98.css 进入首屏带宽竞争；换来的是首帧样式正确，无 FOUC。
