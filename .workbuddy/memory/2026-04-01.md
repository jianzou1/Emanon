- 改造 4 个文件：tabHandler.js / main.js / langManager.js / footerLoader.js
- 核心变更：缓存粒度从 `#main innerHTML` 缩小到内容区域（tablist 之后的兄弟节点）
- Tab 栏不再每次切换时销毁重建，始终保留在 DOM 中
- handlePageLoad 新增 isTabSwitch 双路径，Tab 切换跳过 refreshTabHandler / initCRT / safeBindSwitcher
- langManager 新增 applyTranslationsIn(rootElement) 增量翻译方法
- footerLoader 新增 isTabSwitch 参数，已有 footer 时跳过重建
- popstate 降级处理：从非页签页后退时无 tablist，降级为完整 main.innerHTML 重写
- webpack 构建通过，零 lint 错误

## 画廊 Tab 切换 Bug 修复
- 问题：切换到画廊页签时报错 `Cannot read properties of null (reading 'addEventListener')`
- 根因：gallery.html 的 `#imageModal` 在 `.window-body` 外面、是 `#main` 的直接子元素；但 `getContentHtml` 只提取 `.window-body` 内 tablist 后面的兄弟节点，漏掉了 `#imageModal`
- 修复：缓存格式从字符串改为结构化对象 `{ inner, outer }`
  - `inner`: `.window-body` 内 tablist 后面的兄弟节点 HTML
  - `outer`: `.window-body` 之后的 `#main` 直接子元素 HTML（如 `#imageModal`）
  - `replaceContent` 分两步注入：inner → tablist.insertAdjacentHTML('afterend')，outer → windowBody.insertAdjacentHTML('afterend')
- 同时修复 popstate 降级路径：`cached.inner + cached.outer` 拼接
- 增量翻译范围从 `.window[role="tabpanel"]` 扩大到整个 `#main`
- webpack 构建通过
