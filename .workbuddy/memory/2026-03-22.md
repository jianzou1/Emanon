## CRT 效果性能优化

### 问题分析（Trace-20260322T101403.json）
- **CRT Canvas CLS=0.343**：Canvas 从 600x300 突变为 1566x1910 造成严重布局偏移
- **renderFrame 每帧 ~300-400us**：扫描线逐条 beginPath/stroke，每帧创建 8+ 个 gradient 对象
- **暗角/四角效果每帧重建**：gradient 对象每帧创建一次但实际闪烁极慢
- **DPR=2 导致 Canvas 像素 4 倍**：在高分屏上 Canvas 实际为 3132x3820 像素
- **main.js 同步初始化阻塞**：EvaluateScript 11ms + RunMicrotasks 11ms 阻塞主线程

### 优化实施
1. **Canvas DPR 降采样**（`CONFIG.DPR_SCALE = 0.75`）：Canvas 分辨率降至物理像素的 75%，像素处理量减少约 44%
2. **扫描线路径合并**（`drawScanLinesBatch()`）：同色扫描线合并到单个 Path，`stroke()` 调用从 ~1200 次降至 3 次
3. **静态效果降频**（`STATIC_UPDATE_INTERVAL = 3`）：暗角/四角效果每 3 帧更新一次，gradient 创建减少 67%
4. **CSS CLS 修复**：`.crt-effect` 使用 `100vw/100vh` 替代 `100%`，添加 `contain: strict` + `will-change: contents`
5. **延迟 CRT 初始化**：`initCRT()` 移入 `requestAnimationFrame`，不阻塞首帧渲染
