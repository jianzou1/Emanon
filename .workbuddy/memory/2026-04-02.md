## 修复 Tab 切换不更新 document.title
- **根因**：Tab 缓存切换走快速路径跳过 PJAX，PJAX 的 `selectors: ['head title']` 不生效，没有代码更新 document.title
- `main.js`：TAB_DATA 增加 `titleId` 字段（index_title / article_title / game_title / gallery_title / message_title）
- `tabHandler.js`：新增 `updateTitle(url)` 方法，通过 `langManager.translate(titleId)` 设置 document.title；import langManager
  - 关键：同时更新 `<title>` 的 `data-lang-id` 属性，防止 MutationObserver 全文档翻译覆盖回旧 title
- 在两个缓存路径调用：handleTabClick 缓存命中 + popstate 缓存恢复

## 留言板分页 Bug 修复（两个 bug）
### Bug 1：回复显示不全
- 根因：后端 `get-messages.js` 将主留言和回复混合后扁平分页，导致同一主留言的回复散布在不同分页
- 修复：重构后端分页逻辑——先分离主留言/回复，仅对主留言按时间倒序分页，再附加当前页主留言的全部回复；`total` 改为主留言总数

### Bug 2：回复后刷新丢失页码
- 根因：回复提交后硬编码 `loadMessages(1)`，`initializeMessageBoard()` 也硬编码 `currentPage = 1`，无持久化
- 修复：
  - 新增 sessionStorage 页码持久化（`msg_current_page` / `msg_scroll_target`）
  - 回复提交后 `loadMessages(currentPage)` 保持当前页
  - `initializeMessageBoard` 从 sessionStorage 恢复页码，非第 1 页跳过预取缓存
  - 新增 `scrollToMessage()` 滚动定位 + 2s 蓝色 box-shadow 高亮动画
  - `goToPage` 翻页时同步 sessionStorage
  - 页码越界自动回退到最后一页
  - 主留言提交后清除 sessionStorage（新留言在第一页）

### Mock 数据同步
- `messageBoardMock.js` 重构：先生成全部主留言 → 分页 → 附加当前页回复，与后端一致
