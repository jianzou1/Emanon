# 2026-03-28

## 修复：文章详情页关闭按钮返回后导航栏和内容消失

**问题**：在 article 页面点击进入文章后，点击右上角关闭按钮（`window.history.back()`）返回，导航栏和 window 容器中的内容全部消失。

**根因**：`popstate` 捕获阶段处理器在缓存命中时会注入缓存 HTML 并调用 `handlePageLoad()`，但 PJAX 的 popstate 处理器（冒泡阶段）仍会被触发，发起异步网络请求获取页面。当 PJAX 请求完成后异步替换了 `#main` 内容（替换为服务端返回的空壳 HTML），而 `pjax:complete` 被 `skipNextPjaxComplete` 标志跳过，导致替换后的内容未被初始化（tablist 未填充、文章列表未加载）。

**修复**（`js/main.js`）：
- 在 popstate 捕获阶段处理器中，缓存命中时调用 `event.stopImmediatePropagation()` 彻底阻止 PJAX 的 popstate handler 执行
- 移除了不再需要的 `skipNextPjaxComplete` 标志位及相关逻辑
- 简化了 `pjax:complete` handler
