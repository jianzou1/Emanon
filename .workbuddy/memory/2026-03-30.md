## 留言板调试模式（debug mode）
- 功能：访问 `/page/message.html?debug=1` 时，每条留言和回复下方显示完整 Blob Key（红底白字标签），点击可一键复制到剪贴板
- 用途：在 Netlify 后台 UI 或 CLI (`netlify blobs:delete guestbook "key"`) 中快速定位和删除留言
- 修改文件：
  - `netlify/functions/get-messages.js`：遍历 blobs 时将 `blob.key` 写入 entry 的 `blobKey` 字段返回
  - `js/messageBoard.js`：新增 `DEBUG_MODE` 常量（`?debug=1` 触发），`buildMessageCard` 中条件渲染 `.msg-debug-tag` 元素，点击调用 `navigator.clipboard.writeText()` 复制
  - `css/message.css`：新增 `.msg-debug-tag` 样式（monospace、`--color-error` 红底、可点击、移动端适配）
- 非 debug 模式完全无影响，无额外 DOM 或数据开销
- webpack 构建通过
