## JSON 配置文件预加载强化
- `dataCache.js` 新增 `warmUpCache(urls)` 导出函数，批量预热 JSON 缓存
- `previewLoader.js` 改造：原生 `fetch('/cfg/article_cfg.json')` → `fetchJSON()`（从 dataCache.js 导入），接入统一缓存层
- `main.js` 在 `prefetchMessages()` 之后，通过 `requestIdleCallback`（timeout: 3000，Safari fallback setTimeout 200ms）低优先级预热 4 个 JSON：article_cfg / game_time_cfg / system_cfg / gallery_cfg
- `lang_cfg.json` 保持最高优先级（`await langManager.init()` 阻塞式首步），不参与预热
- 构建验证通过（webpack 5，825ms）
